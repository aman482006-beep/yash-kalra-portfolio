# Yash Kalra & GOAT LIFE - Portfolio Case Study

A modern, frontend-only portfolio website showcasing entrepreneur Yash Kalra and his company GOAT LIFE.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎨 Features

- ✨ Modern React with Vite
- 🎭 Smooth animations with Framer Motion
- 🎨 Tailwind CSS with custom design system
- 📱 Fully responsive mobile-first design
- 🚀 Deploy-ready for Vercel/Netlify

## 🌈 Design System

### Color Palette
- **Background**: #FFFFFF
- **Primary Text**: #111111
- **Secondary Text**: #6B7280
- **Accent**: #FF7A00
- **Highlight**: #FFF6E9
- **Success**: #22C55E

### Typography
- **Headings**: Inter, Poppins
- **Body**: Roboto, Open Sans

## 📦 Tech Stack

- React 18
- Vite 7
- Tailwind CSS 3
- Framer Motion 11
- JavaScript (ES6+)

## 🚀 Deployment

### Vercel (Recommended)
```bash
npm install -g vercel
vercel
```

### Netlify
```bash
npm run build
npm install -g netlify-cli
netlify deploy --prod
```

## 📄 Sections

1. **Hero** - Animated introduction
2. **About Yash** - Personal journey and philosophy
3. **About GOAT LIFE** - Company overview
4. **Metrics Dashboard** - Impact metrics with animated counters
5. **Campaign Showcase** - Marketing initiatives
6. **Company Links** - External connections
7. **Footer** - Disclaimer and social links

- Optimized production builds
